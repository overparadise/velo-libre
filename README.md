# Vélo Libre

Site pour piloter un vélo d'appartement Decathlon Domyos (EB 900) en Bluetooth, via le protocole standard FTMS.

- Programmes perso bloc par bloc (durée + résistance), lancés automatiquement
- Écran séance façon cockpit : compteurs vitesse / cadence, résistance en LED
- Coach perte de poids : séance qui s'ajuste au cardio, progression d'une séance à l'autre
- Cardio externe (Apple Watch via HeartCast, ceinture cardio Bluetooth)
- Suivi du poids et historique des séances

## Utilisation

Ouvrir le site dans **Chrome** ou **Edge** (PC / Android). Sur iPhone, utiliser le navigateur **Bluefy** (Safari ne gère pas le Bluetooth web).

Les données (programmes, poids, séances) restent dans le navigateur, rien n'est envoyé sur internet.
